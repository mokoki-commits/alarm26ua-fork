ПАСПОРТ-ШПАРГАЛКА: НАСТРОЙКА ЛОКАЛЬНОГО УПРАВЛЕНИЯ TUYA БЕЗ ОБЛАКА
========================================================================

Цель: Один раз забрать из облака Tuya статический ключ шифрования 
(Local Key) и управлять устройствами напрямую по локальной сети с 
Linux-сервера (через библиотеку tinytuya) — без интернета и зависимости 
от срока действия облачных подписок.

------------------------------------------------------------------------
ЭТАП 1. РЕГИСТРАЦИЯ И СОЗДАНИЕ ПРОЕКТА НА TUYA IOT PLATFORM
------------------------------------------------------------------------
1. Перейдите на https://platform.tuya.com/ и зарегистрируйте аккаунт 
   разработчика (подойдет любая почта).
2. В левом меню откройте: Cloud -> Project Management и нажмите 
   Create Cloud Project.
3. Заполните параметры строго так:
   - Project Name: любое название (например, HomeLocal).
   - Industry: Smart Home.
   - Development Method: Smart Home 
     (ВАЖНО: не выбирать Industry Solutions, иначе не будет привязки 
     обычного мобильного приложения!).
   - Data Center: выберите дата-центр, соответствующий вашему региону 
     регистрации в приложении (для Украины и Европы — Central Europe 
     Data Center).

------------------------------------------------------------------------
ЭТАП 2. ПОДКЛЮЧЕНИЕ БЕСПЛАТНОЙ ПОДПИСКИ И API-СЕРВИСОВ
------------------------------------------------------------------------
После создания проекта портал предложит выбрать API-сервисы (либо 
зайдите во вкладку Service API внутри проекта -> Go to Authorize).

1. Оформите бесплатный тариф (защита от ошибки 28841001):
   - Перейдите в Cloud -> Cloud Services -> найдите IoT Core.
   - Нажмите Subscribe -> выберите Trial Edition (0 $) и подтвердите.

2. Авторизуйте сервисы в проекте (защита от ошибки 1106):
   - Откройте ваш проект -> вкладка Service API -> Go to Authorize.
   - Обязательно добавьте и сохраните следующие 3 сервиса:
     * IoT Core
     * Authorization Token Management
     * Smart Home Device System

------------------------------------------------------------------------
ЭТАП 3. ПРИВЯЗКА МОБИЛЬНОГО АККАУНТА SMART LIFE / TUYA SMART
------------------------------------------------------------------------
1. Откройте ваш проект -> перейдите на вкладку Devices -> подвкладка 
   Link Tuya App Account.
   (НЕ заходить в «Add Devices with Smart Industry App» и НЕ трогать 
   вкладку «App Authorization» с настройками iOS SDK).
2. Нажмите Add App Account — на экране появится QR-код.
3. На смартфоне откройте приложение Smart Life (или Tuya Smart):
   - Перейдите на вкладку «Я» (Me).
   - Нажмите иконку сканера в правом верхнем углу.
   - Отсканируйте QR-код с экрана ПК и подтвердите привязку.
4. Перейдите на вкладку All Devices в проекте на сайте и убедитесь, 
   что ваши устройства появились в списке. 
   ОБЯЗАТЕЛЬНО скопируйте оттуда точный Device ID нужного устройства.

------------------------------------------------------------------------
ЭТАП 4. ВЫГРУЗКА КЛЮЧЕЙ НА LINUX-СЕРВЕРЕ
------------------------------------------------------------------------
1. Установите библиотеку tinytuya:
   pip3 install tinytuya

2. Запустите мастер настройки:
   python3 -m tinytuya wizard

3. Введите данные из вкладки Overview вашего проекта на сайте:
   - API Key / Client ID
   - API Secret / Client Secret
   - Region: eu (для Central Europe)
   - На вопрос о сканировании локальной сети ответьте: Y

4. После завершения работы мастера проверьте созданный файл snapshot.json 
   (или devices.json):
   cat snapshot.json

5. КРИТИЧЕСКАЯ ПРОВЕРКА:
   Убедитесь, что в файле прописан именно тот Device ID, который вы 
   скопировали на сайте Tuya в пункте 3.4, а в поле "key" появился 
   16-значный локальный ключ. Если ID не совпадает, впишите правильный 
   Device ID вручную (nano snapshot.json) и повторно запустите мастер.

6. Проверьте локальный опрос устройств:
   python3 -m tinytuya

------------------------------------------------------------------------
ВАЖНЫЕ ПРАВИЛА ЭКСПЛУАТАЦИИ
------------------------------------------------------------------------
* Срок подписки (1 месяц): Пробный период IoT Core нужен ТОЛЬКО ОДИН РАЗ 
  для скачивания Local Key. После сохранения файла snapshot.json облако 
  Tuya больше не используется. Когда месяц закончится, локальные скрипты 
  продолжат работать без ограничений.
* Добавление новых устройств в будущем: Если через месяц потребуется 
  добавить новое устройство, в разделе Cloud -> Cloud Services -> IoT Core 
  можно бесплатно продлить триал (Extend Trial Period) либо просто создать 
  новый облачный проект с новой бесплатной подпиской и выгрузить ключ.
* Сохранность ключа: Сделайте резервную копию snapshot.json / devices.json. 
  Local Key остается неизменным до тех пор, пока устройство не будет 
  сброшено к заводским настройкам и заново добавлено в приложение.
